# 作成ルール
以下のルールに従って、指定されたパスに新しいファイルを作成してください：
- 1. 指定されたディレクトリに新しいファイルを作成してください。
- 2. ファイルの内容は、指定されたプログラミング言語で記述してください。
- 3. 1,2の情報がユーザプロンプトにない場合、必ずユーザに確認してください。
- 3. 先頭行に"新規作成：[YYYY-MM-DD]"のコメントを付与してください。
- 4. 2行目に"作成者：[モデル名]"のコメントを付与してください。
- 5. クラスの場合、物理名はアッパーキャメルケースで命名してください。
- 6. 関数の場合、物理名はスネークケースで命名してください。
- 7. 変数の場合、物理名はローワーキャメルケースで命名してください。
- 8. 処理の要所にコメントを追加してください。
- 9. コードの可読性を高めるために適切なインデントを使用してください。

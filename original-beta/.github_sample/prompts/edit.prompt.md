# 作成ルール
以下のルールに従って、指定されたパスに新しいファイルを作成してください：
- 1.  指定されたファイルに更新を加えてください。
- 2.  ファイルの更新内容はユーザの指示に従ってください。
- 3.  1,2の情報がユーザプロンプトにない場合、必ずユーザに確認してください。
- 4.  ユーザ指示と無関係の箇所は変更しないでください。
- 5.  ファイル上部に"最終更新日：[YYYY-MM-DD]"のコメントを付与してください。
- 6.  更新日の直下に"最終更新者：[モデル名]"のコメントを付与してください。
- 7.  更新を加える際は"---更新開始：[YYYY-MM-DD]---"と"---更新終了：[YYYY-MM-DD]---"のコメントで囲んでください。
- 8.  クラスを追加する場合、物理名はアッパーキャメルケースで命名してください。
- 9.  関数を追加する場合、物理名はスネークケースで命名してください。
- 10. 変数を追加する場合、物理名はローワーキャメルケースで命名してください。
- 11. 処理の要所にコメントを追加してください。
- 12. コードの可読性を高めるために適切なインデントを使用してください。

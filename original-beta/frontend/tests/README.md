# フロントエンド テスト README

このディレクトリには、Jestで実行するフロントエンドのユニットテストが含まれています。

## 必要要件

- Node.js と npm（または pnpm/yarn）
- frontend 配下に依存関係がインストール済みであること

## インストール

リポジトリのルートから実行してください。

```bash
cd frontend
npm install
```

## テスト実行

```bash
cd frontend
npm test
```

## 補足

- Jest 設定: `frontend/jest.config.js`
- テストファイルの配置: `frontend/tests/code/frontend`
